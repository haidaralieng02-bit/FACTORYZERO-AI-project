# 3-Minute Hackathon Demo
1. Start on the FactoryZero AI dashboard.
2. Point out Demo / Simulated Result mode.
3. Click Run Investigation.
4. Show rising temperature, vibration and current.
5. Show electrical and mechanical hypotheses separately.
6. Show the Evidence tab with document/page metadata.
7. Show inspection-first maintenance plan.
8. Show deterministic production impact: 100 units/hour × 2 hours = 200 units.
9. Open Verification and show schema/evidence/arithmetic/safety/confidence checks.
10. Download the report.

Say explicitly: synthetic data, decision support only, no autonomous machinery control.
