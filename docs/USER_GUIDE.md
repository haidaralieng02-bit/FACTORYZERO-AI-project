# User Guide
1. Open the app.
2. Start with Demo Mode.
3. Upload telemetry/documents for a custom incident if desired.
4. Enter machine information.
5. Click Run Investigation.
6. Watch agent progress.
7. Review telemetry and separate electrical/mechanical hypotheses.
8. Review evidence and citations.
9. Review maintenance plan and safety notes.
10. Review production impact.
11. Review verification.
12. Download the final JSON/TXT report.
